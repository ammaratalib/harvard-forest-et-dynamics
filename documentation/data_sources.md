# Data sources and repository policy

## Source records

The analysis combines eddy-covariance, meteorological, phenology, and soil-moisture measurements from AmeriFlux and the Harvard Forest Data Archive.

| Record | Use in this study | Persistent identifier |
|---|---|---|
| US-Ha1 eddy-covariance data | EMS carbon, water, energy, and meteorological observations | https://doi.org/10.17190/AMF/1246059 |
| US-Ha2 eddy-covariance data | HEM carbon, water, energy, and meteorological observations | https://doi.org/10.17190/AMF/1246060 |
| HF004 | Long-term EMS tower record | https://doi.org/10.6073/pasta/56c6fe02a07e8a8aaff44a43a9d9a6a5 |
| HF206 | Upper-soil-moisture sensitivity analysis | https://doi.org/10.6073/pasta/43f37233c7c9ee1513d674ea2a0510c7 |
| Harvard Forest daily meteorology | Daily precipitation | https://doi.org/10.6073/pasta/a7eb36231cbed30cea58b77af62945f1 |

## Files stored here

The repository contains derived gap-filled site tables, standardized TEA inputs, compact daily tables, conductance inputs, daily soil-moisture tables, annual ET-partitioning results, revised PET products, XGBoost validation results, and manuscript figures. These are the products most directly connected to the reported values.

## Files not stored here

Raw AmeriFlux and Harvard Forest archive downloads are omitted. Several exceed GitHub's per-file limit, and the original data providers maintain authoritative, citable copies. Users who need to reconstruct the preprocessing workflow should download those records from the persistent links above and follow the data providers' use policies.
